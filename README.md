# block-ai-overview
a chrome extension to remove the ai overview from google searches by adding -ai to queries

## instructions
in chrome, go to "manage extensions"
turn on developer mode
select "load unpacked" and select the folder for this repo
recommended: pin the extension to the chrome taskbar - you can toggle it on/off. 🤖 = ai overview active. 🚫 = ai overview disabled. 
if you love this, let me know!
